How to use this system

  1. Upload an MCAP file and select your name as technician
  2. Review the automated extraction results on the Analysis Page
  3. Save the Analysis Summary, then complete the verification form
  4. Generate the PDF report once the analysis is marked Completed
  5. Find and download all reports from the Reports Page
